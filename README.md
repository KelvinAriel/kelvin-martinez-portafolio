# Portafolio docente de Kelvin Ariel Martínez Lara

Sitio web elaborado para la asignatura Práctica Docente (DDP1109) de la Licenciatura en Informática Educativa, Universidad de El Salvador.

## Publicación

El proyecto está preparado para publicarse con GitHub Pages desde la rama `main` y la carpeta raíz.

## Estructura

- `index.html`: contenido y estructura del portafolio.
- `styles.css`: diseño visual y adaptación a dispositivos móviles.
- `script.js`: navegación interactiva.
